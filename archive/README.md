# Archive

Earlier versions of the project, kept for reference. Nothing here is used by the current
simulation (`index.html` and `app/` at the repository root).

- `processing/AntColony/` – the original Processing (Java) sketch. Open `AntColony.pde` in the
  Processing IDE and press Run.
- `p5-single-file/sketch.js` – the first JavaScript port: the whole sketch in one p5.js file,
  before it was split into modules.
- `docs/` – the original documentation: the project write-up (`Documents/`) and the UML class
  diagram made with Unimozer (`Diagram/`, see its `README.txt`).
